                        ⚙️ Optimization (Gifsicle)
                    


                    

                    


                        


                            

                            

                        


                        


                            

                            

                            
                                (1 = perfect · 200 = tiny)
                            

                        


                        


                            

                            

                        


                        


                            

                        


                    


                    


                        Gifsicle applies dirty-rectangle
                        compression, per-frame palette
                        optimization and LZW tuning — often
                        reducing file size by 30–60% compared
                        to the raw encoder output.

                        



                        Colors: number of colors
                        in the palette. 256 = max (GIF format
                        limit). Lower = smaller file but more
                        banding.

                        


                        Dither: applies dithering
                        to reduce visible banding at low color
                        counts. Slightly larger file but smoother
                        gradients.
