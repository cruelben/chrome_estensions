# Save WebP as JPG

A simple Google Chrome extension (Manifest V3) that lets you **convert and save any WebP image as JPG** on the fly, directly from the browser's right-click context menu.

---

## ✨ Features

- 🖱️ **Context menu integration**: right-click any image and select "Save WebP as JPG".
- 🖼️ **Automatic conversion** from WebP (or any other browser-supported format) to JPEG.
- 🏷️ **Unique filename**: every saved image is named with the exact date and time (down to milliseconds), e.g. `20260927_154123456.jpg`.
- ⚙️ **Adjustable JPEG quality** (set to `0.92` by default in the code).
- 🚀 **No external dependencies**: everything happens locally in the browser, with no data sent to external servers.
- 🔒 **Privacy guaranteed**: no data is collected or transmitted.
